## Filming Notes

- Use screen recording software (OBS, Loom, or QuickTime)
- Record at 1920x1080 resolution
- Use cursor highlighting to draw attention
- Add subtle background music (uplifting, inspirational)
- Use text overlays for key features
- Keep transitions smooth and professional
- Export at 30fps, H.264 codec
- Add closed captions for accessibility
